# How to use the new login page

## Prerequisites
API and website running.

## Steps
1. Open `https://localhost:7144`. You see a white panel with the teal Klasly logo, "Log in" and "Attendance and grades for your classes."
2. Enter your email and password and press **Log in**. The button changes to "Logging in…".
3. If the details are wrong, the red message appears inside the panel above the fields.

## Example
After your session expires, the message "Your session ended, please log in again." appears inside the login panel.

## Troubleshooting
- **"Klasly can't reach the server right now."**: the API isn't running.
- **Students can't log in here**: by design; students use the Klasly Android app.
